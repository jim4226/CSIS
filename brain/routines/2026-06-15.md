## Items considered

### opened-PR — Paving the way for agents in biology
- URL: https://www.anthropic.com/research/agents-in-biology
- Source: anthropic.com/research, published 2026-06-08
- Theme: 2 — Trust + verification
- Touches: `csis/contracts.py:GraderResult`, `csis/verification/graders.py`
- Size: small (~70 LOC net)
- Risk: low
- PR: #59

The paper's central finding is that deterministic retrieval tools and structured
execution logs — showing *how* a result was produced, not just *what* it was —
transform unreliable agent outputs into auditable, reproducible ones. CSIS's
`GraderResult` had a freeform `detail` string but no structured execution path.
Added `trace: list[str]` (optional, default `[]`, backward-compatible) and
populated it in all six Phase-0 graders to capture key lookups, threshold
checks, and the PASS/FAIL decision step.

### opened-PR — Claude Fable 5 and Mythos 5 (tripwire retention)
- URL: https://www.anthropic.com/news/claude-fable-5-mythos-5
- Source: anthropic.com/news, published 2026-06-09
- Theme: 3 — Constitutional / safety primitives
- Touches: `csis/safety/tripwires.py:Tripwires`
- Size: small (~40 LOC net)
- Risk: low
- PR: #60

Fable 5 uses a 30-day data retention window to detect attack patterns that
operate across many requests — not just single-turn attacks. CSIS's `Tripwires`
class had count-bounded history (`deque(maxlen=10000)`) but no time dimension.
Added `fired_at: float` to `TripwireFiring` (default `time.time()` at
construction, backward-compatible) and `retention_seconds: float | None` to
`Tripwires.__init__`. When set, `history()`, `history_size()`, and `fired()`
filter out entries older than the window. Expiry is lazy (on read), no
background thread.

### deferred — Deterministic Memory Retrieval Interface
- URL: https://www.anthropic.com/research/agents-in-biology (sub-insight)
- Source: same paper as PR #59
- Theme: 4 — Persistent memory + context
- Touches: `csis/memory/store.py:MemoryHierarchy`, `csis/agents/librarian.py`
- Size: medium (~100–150 LOC for a proper search API)
- Risk: low-medium (adds new public method to MemoryHierarchy used by Coordinator)
- Design sketch: Add `MemoryHierarchy.search(query: str, tier: str | None, *, role: str) -> list[MemoryEntry]` doing substring/keyword matching on `content` — deterministic, no LLM, O(n). Long-term this becomes the retrieval endpoint for the Dreams-integrated semantic search (P1.1). The paper's `gget virus` abstraction shows that even a simple deterministic retrieval layer beats "let the LLM navigate the raw interface."
- Why deferred: The right semantics (substring? BM25? exact tag match?) depend on how P1.1 Dreams API shapes the query interface. Locking in a naive substring API now would create a migration scar when real retrieval arrives. Revisit after P1.1 design is settled.
