### deferred — Claude Science: provenance-tracked reviewer-agent verification
- URL: https://www.anthropic.com/news/claude-science-ai-workbench
- Source: anthropic.com/news, published 2026-06-30
- Theme: 2 (Trust + verification) and 1 (Multi-agent coordination — specialist + reviewer agent)
- Touches: `csis/agents/verifier.py`, `csis/verification/certificates.py`, the Auditor why-doc path in `csis/agents/coordinator.py` — this is the same seam as `ROADMAP.md` P1.8 ("LLM-generated why-doc summaries")
- Size: medium
- Risk: medium (adjacent to, though not one of, the four named cycle-9 chokepoints — the Auditor gate)
- Design sketch: Claude Science bundles "the exact code and environment that produced it, a plain-language description of how it was created, and the full message history" with every generated artifact, and runs a dedicated reviewer agent that flags "incorrect citations, untraceable numbers, and figures that don't match their underlying code," self-correcting as it goes. CSIS's Auditor already writes a why-doc, but per README/ROADMAP it's templated, not LLM-authored from the structured query results (P1.8). A Phase-1 why-doc could carry the same three provenance fields (diff/code, environment snapshot, full message history) instead of template text, and the existing V2 critic could get an explicit "does every claim trace to evidence" pass modeled on Claude Science's reviewer agent — reusing the cross-checkpoint V1+V2 pattern CSIS already has rather than adding a new agent role.
- Why deferred: P1.8 is an already-acknowledged Phase-1 item that "requires another tripwire pass on the LLM output before promote" per `ROADMAP.md`; this needs cross-cycle discussion before landing given proximity to the Auditor/promotion gate, and is medium-or-larger by the routine's own sizing bar.
