### deferred — Paving the way for agents in biology
- URL: https://www.anthropic.com/research/agents-in-biology
- Source: anthropic.com/research, published 2026-06-08
- Theme: 6 — Substrate / capability boundaries; 2 — Trust + verification
- Touches: `csis/domains/base.py` (Domain ABC), `csis/verification/graders.py` (GraderRegistry)
- Size: small–medium
- Risk: low-medium (touches grader interface, not cycle-9 chokepoints)
- Design sketch: The paper's core finding is that agents achieving 16–91% accuracy on deterministic retrieval tasks jump to 99.7% when given a deterministic wrapper layer ("context engine"). CSIS's V1 graders are already pure functions (`Callable[[Artifact], GraderResult]`), which is the right direction. The PR would: (1) add a `DeterministicGrader` protocol type annotation to `csis/domains/base.py` to make the determinism expectation explicit; (2) add a `lint_grader_determinism` check to `GraderRegistry.verify_pinned_hashes` that detects graders importing `random` or `time` at the function level; (3) update `csis/verification/graders.py` docstring to explicitly prohibit external API calls in graders and require all uncertainty to be pushed to artifact.extra inputs.
- Why deferred: The proposed `lint_grader_determinism` check requires inspecting grader source code for imports, which is an extension of the existing `inspect.getsource` path. Needs a design discussion on whether to use AST parsing vs. regex, and whether to make it a hard error (refusing certs) or a warning. This is the right direction but medium design work; deferring for the next run with a concrete proposal.
