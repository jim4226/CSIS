- Note: PR #42 (2026-06-08, grader-provenance-layer) addressed execution provenance from the same paper — a different CSIS surface (`csis/verification/graders.py`). This PR addresses the deterministic retrieval *declaration point* at the domain level. For CSIS, each domain adapter now has an optional `context_engine()` that returns a `ContextEngine(label, fetch)` or `None`.
