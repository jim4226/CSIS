### deferred — Inference hooks
- URL: https://platform.claude.com/docs/en/manage-claude/inference-hooks
- Source: platform.claude.com release notes, published 2026-08-05
- Theme: 3 — Constitutional / safety primitives (tripwires, capability tiers) and 6 — Substrate / capability boundaries
- Touches: `csis/safety/tripwires.py`, `csis/agents/coordinator.py` (`Coordinator.__init__` is the natural insertion point — it's the one place every LLM call already passes through per the cycle-9 H1 fix)
- Size: medium-to-large
- Risk: high (any change here sits directly on the cycle-9 chokepoint)
- Design sketch: Anthropic's Inference hooks route every governed prompt through an external "AI security server" for a signed allow/deny verdict *before* inference, with a configurable verdict timeout (default 5s), configurable fail-open/fail-closed on timeout/error, staged rollout (shadow mode → percentage → full), and every denial logged to a compliance Activity Feed. The CSIS analogue: an optional pre-call verdict hook registered on `Coordinator`, invoked immediately before every wrapped-backend call (the same chokepoint `_BackendTracker` already guards). On `deny`, raise the existing tripwire/`HaltSignal` path instead of a new one — no new stop mechanism needed, just a new thing that can trigger the old one. Fail-open/fail-closed and timeout behavior would need to be config, and (per the cycle-9 lesson) the guard has to sit in `Coordinator.__init__` itself, not in `Daemon` or a wrapper a script can bypass.
- Why deferred: this is exactly the shape of chokepoint the cycle-9 red team already found real bypasses around (H1: wrong layer, H3: setattr after init). A change here needs the same rigor — a regression test that fails before and passes after, modeled on `test_H1_coordinator_rejects_unwrapped_backend` — which is more than one routine run should attempt without a slower look. Worth reconsidering as a scoped PR next run: land only the hook-registration + tripwire-raise wiring, no actual HTTP call to an external server (that's meaningfully Phase-1/real-backend territory).
